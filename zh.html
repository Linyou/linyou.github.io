关于林尤添。

林尤添 Youtian Lin

我目前是南京大学的博士研究生，师从姚遥教授，并在曹汛教授与谭铁牛教授的指导下开展研究。此前在 Apple 担任计算机视觉研究实习生。

来南大之前，我在哈尔滨工业大学攻读博士学位。2021 年于哈尔滨工程大学获硕士学位，导师为关健教授。

我还曾在三维生成初创公司 DreamTech（Neural4D）、VAST（Tripo AI）与太极图形（Meshy AI）工作，参与其早期三维生成技术的研发。

  • 三维 / 四维重建与生成
  • 智能体三维建模
  • 神经渲染
  • 生成式模型
  • 高性能 GPU 编程

开源项目。我开发或参与的工具。

  • Procedura 带可编辑部件的智能体三维建模，可通过 MCP 在 Codex 与 Claude Code 中运行。
  • P3D-Bench 评测多模态大模型参数化三维生成的基准与排行榜。
  • Pointrix 用于三维重建与渲染的可微点渲染库。
  • threestudio-3DGS threestudio 框架的高斯泼溅扩展。
  • taichi-nerfs 基于 Taichi 与 PyTorch 的 Instant-NGP 神经辐射场训练流程。
  • taichi-ngp-renderer 用纯 Python 与 Taichi 实现的 Instant-NGP 渲染器。
  • nerfacc 快速 NeRF 加速工具包，贡献者。
